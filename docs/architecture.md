# Architecture and current boundary

React 19, strict TypeScript, React Router and Vite call a same-origin `/api/v1` Go/chi API. TanStack Query owns server state, React Hook Form/Zod validate application/login forms, and react-i18next provides English/Hindi UI. Tailwind v4 and custom tokens style reusable accessible components; Radix handles dialogs and drawers. Frontend types are generated from `contracts/openapi.yaml`.

Go is the only application backend. Packages: `config` (fail-closed startup), `domain` (models/invariants), `storage` (official MongoDB driver v2, repositories, migrations/fixtures), `app` (HTTP, auth, workflow transactions and schedule guards). The first slice intentionally keeps a small modular monolith; split application services further as the next domains arrive.

MongoDB Atlas is configured privately in the root `.env`; it is never available to Vite. The supplied connection was verified and migration/seed commands succeeded against `tutor_dev`. Integration and E2E tools create separately named databases on that same cluster. They retain their own test records for review and do not drop or overwrite existing databases. See progress for executed evidence. Tests can alternatively use a real local WiredTiger replica set via optional `npm run db:local`; it downloads a MongoDB binary and persists to `.local/mongo`. No Docker is required or included.

User override: email/password replaces OTP. The `password` package uses salted Argon2id (19 MiB, 2 iterations, 1 lane); credentials are stored separately under normalized unique email IDs. Signup transactionally creates the credential, adult user and session, allowing only parent/tutor roles. Password work is bounded per instance, with persisted per-email/IP rate limits across instances. Login errors do not distinguish unknown email from wrong password. Opaque random session cookies remain HttpOnly/SameSite=Lax; tokens are hashed, explicitly expired, rotated and revoked. Old OTP sessions are rejected by the session method filter. No OTP endpoints, SMS delivery or email-verification claims remain. Production authenticated operations stay disabled pending email recovery/security review, staff provisioning/MFA, guardian verification and operator release review.

The first journey is an online, zero-fee **development trial**. No sandbox payment is configured and no payment success is fabricated. Server-written price and versioned trial terms are persisted. This is not the ongoing tuition agreement/payment/enrollment domain.

Trial acceptance and confirmation are a single transaction in the zero-fee path. It writes the tutor application version, serializing against approval/suspension changes, and authoritative tutor/day plus learner/day guard records. Each guard has bounded intervals; writers contend on its version. Both UTC dates are locked across midnight. Cancellation removes reservations under the same locks. Guard initialization is idempotent before the transaction. MongoDB transaction callbacks run sequentially and make no external calls. A unique actor/idempotency-key record stores a body fingerprint and original result. The conflict test sends concurrent HTTP requests to separate API instances with separate database clients.

Not implemented: paid holds, recurring schedules, travel buffers, general availability/capacity, outbox delivery workers, ongoing enrollments, messaging, uploads, payments/ledger, or learning-plan version/handover operations. Suspension creates a persisted `pending_operator` operations task; it does not pretend a worker or notification has run.

Deployment: GitHub source/CI → build artifact → DigitalOcean droplet. Nginx serves static React files and proxies API requests to a loopback Go service managed by systemd. Atlas remains external. Node is unnecessary in the running application if artifacts are built in CI. No public deployment was performed. Public tutor pages currently use client rendering; marketing pre-rendering and dynamic SEO work remain open.
